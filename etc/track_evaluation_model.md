# Модель Справедливой Оценки Трека

Эта модель предназначена для справедливой оценки музыкальных треков разных жанров путем эмуляции "попадания в целевую аудиторию". Вместо единой шкалы для всех, оценка производится по критериям, значимым для конкретного жанра.

## Шаг 1: Критерии Оценки

Каждый трек оценивается по 7 ключевым критериям по шкале от 1 до 10. Оценщик должен мысленно стать представителем ЦА жанра и ответить на вопрос: "Насколько это хорошо для фаната этого стиля?"

*   **1. Техника и Исполнение**: Оценивается чистота вокала/речитатива, владение инструментом, ритмичность, подача. *Насколько технично это для панка? Насколько крутая читка для рэпа?*
*   **2. Композиция и Мелодия**: Структура трека (куплеты, припевы), качество и запоминаемость мелодий, гармонических ходов. *Насколько цепляющая мелодия для поп-хита? Насколько качающий рифф для метала?*
*   **3. Аранжировка и Звучание**: Выбор инструментов, их взаимодействие, плотность и фактура звука, саунд-дизайн. *Насколько богатая аранжировка для синт-попа? Насколько она создаёт нужную атмосферу в эмбиенте?*
*   **4. Качество Продакшна**: Техническое качество записи, сведения и мастеринга. Чистота, баланс, динамика. *Этот критерий более универсален, но даже в lo-fi жанрах есть свои стандарты "правильного" грязного звука.*
*   **5. Текст и Лирика**: Смысловая нагрузка, качество рифм, образы, сторителлинг, оригинальность темы. *Насколько глубокий текст для авторской песни? Насколько изобретательные панчи для баттл-рэпа?*
*   **6. Оригинальность и "Хуки"**: Насколько свежо это звучит в рамках жанра? Есть ли в треке "крючки" — цепляющие моменты, которые остаются в памяти? *Даже в самом традиционном жанре можно сделать что-то по-новому.*
*   **7. Атмосфера и Попадание в ЦА**: Создаёт ли трек нужное настроение? Вызывает ли эмоции, которые ждёт слушатель этого жанра? *Качает ли дэнс-трек? Погружает ли в транс эмбиент?*

## Шаг 2: Взвешенная оценка

Итоговая оценка рассчитывается как сумма произведений оценки по каждому критерию на его весовой коэффициент для данного жанра. Сумма весов для каждого жанра равна 100%.
