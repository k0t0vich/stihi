Место Участник Песня Сырой Коэф. Итог
Как читать. «Сырой» — сумма баллов по шкале. «Коэф.» — поправка на то, сколько судей могли проголосовать за участника: голосующий не может выбрать себя, поэтому его электорат на одного меньше. «Итог» — сырой балл, умноженный на коэффициент. Стрелка у места показывает сдвиг относительно сырого рейтинга.

Ничьи помечены знаком ≈ — совпадение по итоговому баллу. Разрешаются по числу первых мест, затем вторых, затем третьих. Клик по строке — разбор, кто и сколько баллов дал.
