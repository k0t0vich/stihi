# Промпт-установщик

Распакуй `reaper-claude-kit.zip`, открой Claude Code в папке `reaper-claude-kit` и вставь текст ниже целиком.

---

```text
В этой папке — комплект для работы с REAPER: скиллы (skills/), скрипты (scripts/), цепочки FX (fxchains/), семплы баса, автозапуск моста MCP (mcp/) и инструкция INSTALL.md. Собран на чужой машине, у меня может быть иначе. Помоги поставить его под меня.

0. Комплект написан под macOS. Если у меня Windows (или Linux) — сначала перепиши его под мою систему: путь к REAPER (reaper.exe), ресурсная папка (%APPDATA%\REAPER вместо ~/Library/Application Support/REAPER), имена кэшей плагинов (reaper-vstplugins64.ini), afconvert → ffmpeg, sysctl в plugin_scan.py, python из venv (.venv\Scripts\python.exe), установку моста вместо install_bridge.sh. Покажи, что поменял, и проверяй дальше уже переписанное.
1. Прочитай INSTALL.md и все SKILL.md. Составь список того, что комплекту нужно: программы, плагины, Python-пакеты, MCP-сервер, пути.
2. Проверь, что из этого у меня уже есть: REAPER и его ресурсная папка, Python и пакеты, плагины (по кэшам REAPER — scripts/plugin_scan.py), Claude Code, MCP-сервер REAPER. Покажи таблицу: есть / нет / другая версия.
3. Чего нет — предложи, как поставить. Бесплатное (Python-пакеты, MCP-сервер, мост, скрипты) ставь сам после моего «да». Платные плагины не покупай — скажи, чем заменить из того, что у меня есть, и поправь шаблоны и план сведения под замену.
4. Поставь MCP-сервер REAPER и мост, подключи к Claude Code, проверь связь: прочитай список дорожек открытого проекта.
5. Разложи скиллы в ~/.claude/skills, скрипты — туда, куда скажу (по умолчанию ~/reaper-claude-kit), и поправь пути в SKILL.md.
6. Проверь работоспособность на пробе: пример scripts/songs/grunge_demo.py через song_kit.py в пустую папку, рендер, замер mix_probe.py. Если что-то молчит или падает — разберись и почини.
7. Каталогизируй, что получилось: какой скилл что умеет и что ему нужно.
8. Спроси меня в диалоге, на какие фразы и в какие моменты подключать каждый скилл и скрипт, и впиши ответы в description скиллов.

Ничего не удаляй и не перезаписывай без спроса: мои проекты REAPER, __startup.lua, существующие скиллы. Перед каждым шагом, который что-то ставит, — коротко скажи, что будет.
```
