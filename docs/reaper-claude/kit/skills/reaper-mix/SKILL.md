# Сведение и мастеринг в REAPER

Инструменты — `~/reaper-claude-kit/scripts/`: `mix_probe.py` (замер), `mix_apply.py`
(план → плагины), `mix_calibrate.py` (пороги по подавлению). Шаблон плана —
`plan_template.json` рядом, каждое число с полем `why`.

## Порядок

| Шаг | Команда | Что даёт |
|---|---|---|
| 1. замер «до» | `mix_probe.py render ПРОЕКТ/mix/00_before` → `analyze` | LUFS-I/LRA/TP/PLR по стемам, кто занимает полосу, стерео по полосам, тональный баланс, корреляция низа |
| 2. план | `ПРОЕКТ/mix/plan/plan.json` из шаблона, правки по замеру | каждое число — из замера или таблицы ниже |
| 3. применить к копии | `mix_apply.py plan.json --copy-to ПРОЕКТ/<имя>_mix_ГГГГММДД_ЧЧММСС.rpp` | исходный проект не трогается, копия в новой вкладке |
| 4. калибровка компрессоров | `mix_calibrate.py ПРОЕКТ/mix/calib --from 26.7 --to 44.4 --comp "тег:цель:ratio" ... --makeup` | порог под целевое подавление на громком отрезке; makeup = подавление |
| 5. проверка подавления по звуку | `render --bypass "теги компрессоров"` против рендера с ними | огибающая 50 мс: среднее, p10–p90 — дышит ли компрессор |
| 6. лимитер | цикл: `render` → LUFS → `mix_apply.py --set "лимитер:Gain=X"` | попадание ±0.2 LU; шаг ≈ 1.15 × промах |
| 7. итог | `analyze 06_… --ref 00_before`, сохранить копию | таблица «было → стало» пользователю, слушает он |

Повторный `mix_apply.py plan.json` (без `--copy-to`) пересобирает цепочки «mix: …»
в активной вкладке — **сбрасывает калибровку**, поэтому откалиброванные пороги и
makeup сначала вписать в план. Точечно — `--set "тег:Параметр=значение"`.
Перед сохранением проверить по `GetProjectName`, что активна копия.

## Числа из источников (подробно с URL — `SOURCES.md`)

| Что | Значение |
|---|---|
| бас | HPF 30–40 Гц; компрессия 4–5:1, 4–5 дБ GR (SOS); «рык» — сатурация верхней середины, LPF ~3–4 кГц |
| гитары (дабл, перегруз) | HPF 100–120, LPF 10–12k, муть 250–500 −2…−4, резкость 3–4k −2…−3; плотность — +4–5 дБ на 200/600 (SOS) или сатурация; шина 1–2 дБ GR |
| шина ударных | 2:1, атака ~30–35 мс, release ~100 мс, ~3 дБ GR (SOS) |
| склейка мастера | 2:1, атака 10–30 мс, auto release, 1–3 дБ GR |
| общий ревер | один на ударные и гитары, pre-delay 20–30 мс, бас не посылать, ~20 дБ под миксом |
| мастер | клиппер 1–2 дБ → true-peak лимитер 2–4 дБ, потолок −1 dBTP; PSR ≥ 8, PLR ≥ 12 (расходятся) |
| наклон 4.5 дБ/окт | это дефолт отображения SPAN, **не цель**; сравнивать с референсом |

## Плагины (VST3, имена параметров для плана)

| Плагин | Параметры |
|---|---|
| `VST3: Pro-Q 4 (FabFilter)` | `Band N Used` = Used, `Shape` (Bell / Low Cut / High Cut / Low Shelf / High Shelf), `Frequency` Гц, `Gain` дБ, `Q`, `Slope` («24 dB/oct») |
| `VST3: Pro-C 2 (FabFilter)` | `Style` (Clean / Bus / Opto / …), `Threshold`, `Ratio`, `Knee`, `Attack`/`Release` мс, `Auto Release`, `Auto Gain` = Off, `Output Level` = makeup |
| `VST3: Saturn 2 (FabFilter)` | `Band 1 Drive` %, `Band 1 Mix` %, `Band 1 Style` (по умолчанию Warm Tape) |
| `VST3: Pro-L 2 (FabFilter)` | `Style` Modern, `Oversampling` 4x, `True Peak Limiting` On, `Output Level` −1, `Gain` |
| `VST3: Pro-R 2 (FabFilter)` | `Space` (в плане в мс), `Predelay` мс, `Mix` % |
| ещё есть | Pro-MB, Pro-DS, Pro-G, Timeless 3, Volcano 3, Ozone 12 по модулям, Nectar 4; полный список — скилл `reaper-plugins` |

## Грабли

| Что | Как правильно |
|---|---|
| порог «на глаз» | Pro-C 2 с коленом 18 дБ по умолчанию срезал бас на 16.6 дБ, ударные на 9 — колено 6 и калибровка |
| симуляция детектора в Python | врёт: на шине гитар обещала 1.5 дБ, плагин давал 8.5. Мерить `GainReduction_dB` (среднее сходится со звуком ±0.05 дБ) |
| `GainReduction_dB` | сглаженное: максимум ≈ среднему. Динамику подавления — только по разнице рендеров |
| FX пре-фейдерные | вход плагина = стем − фейдер; бас и AD2 приходят с пиками около 0 dBFS |
| folder-шина в рендере стемов | её стем = сумма детей после обработки шины; стемы детей — до шины |
| LUFS без ffmpeg/pyloudnorm | свой BS.1770-4 в `mix_probe.py`; синус 997 Гц 0 dBFS: −3.01 / 0.00 — сверено, и с `CalculateNormalization` REAPER ±0.01 |
| `render` меняет настройки рендера | lua возвращает их как были |
| мастер пользователя (Ozone) | не удалять — `bypass_master` выключает |
| калибровка играет вслух | предупредить: каждый проход — звук на 18 с |
