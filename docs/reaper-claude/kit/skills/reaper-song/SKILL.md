# Демо-трек в REAPER с нуля

Всё найденное ниже уже проверено — заново не искать.

## 0. Спросить, какие гитары вешать

Перед сборкой — AskUserQuestion (можно несколько):

| Вариант | Что это | `--guitars` |
|---|---|---|
| Ample Guitar VC + Guitar Rig 7 | две дорожки L/R, пресет GR7 «AD In The Desert» | `ample` |
| Odin III, свой усилитель | одна дорожка — плагин сам двоит L/R; приёмы: глушения, скрейп, слайды, пинч, флажолеты (`ODIN.md`) | `odin` |
| обе | сравнить; Ample можно заглушить | `ample,odin` |

Добавить гитары в **уже открытый** проект (не пересобирая):
`reaper_song.py ПАПКА --guitars odin --add` → `ПАПКА/add_odin.lua`, запуск через
`-nonewinst`. Вставляет дорожки в активную вкладку (одноимённые заменяет), Ample
глушит, ставит параметры Odin, **не сохраняет**. Перед запуском проверить по
заголовку окна, что активна нужная вкладка.

## MCP REAPER

Сервер `mcp__reaper__*` работает (`dsl_get_tempo_info` отвечает). «Скилов для
написания музыки» в нём нет: только DSL-команды, `dsl_generate` (AI-генерация)
и `generate_chord_progression` / `generate_scale_run`. Партии надёжнее писать
самим кодом (MIDI), а MCP брать для проверки и мелких правок.
`dsl_list_tracks` на живом проекте отвечает «No tracks found», поэтому индексы дорожек берутся из своего кода.

## Ноты

**AD2 — не GM.** Основные ноты (полная карта: `~/reaper-claude-kit/scripts/ad2_keymap.py`):

| Звук | Нота | Звук | Нота |
|---|---|---|---|
| Kick | 36 | Ride tip / bell | 60 / 61 |
| Snare open / rimshot | 38 / 37 | Crash 1 / 2 / 3 | 77 / 79 / 81 |
| Snare sidestick | 42 | Tom 1 / 2 / 3 / 4 | 71 / 69 / 67 / 65 |
| HiHat closed tip | 49 | HiHat pedal | 48 |
| HiHat open A…D | 54…57 | Cymbal choke | 78 / 80 / 82 |

GM 42 в AD2 — это sidestick, а GM 49 — закрытый хэт. Если писать в GM, партия рассыпается.

**Ample Guitar VC** — стандартный строй, нижняя нота E2 (40). Drop D (38) не
писать: в плагине строй не переключить из файла. Квинты: E5 40-47-52,
G5 43-50-55, A5 45-52-57, C5 48-55-60, D5 50-57-62, B5 47-54-59.

**Бас RS5K** — реальная высота, 28..39. Октавный подхват (+12) не звучит,
вместо него — полутон к следующему корню.

## Сборка проекта

Готовый генератор: `~/reaper-claude-kit/scripts/reaper_song.py` (гранж-демо, 108 bpm,
Intro/Verse/Chorus/Verse/Chorus/Bridge/Chorus/Outro). Новую песню писать, меняя
в нём партии (`guitar`, `bass`, `drums`, `SECTIONS`, `CHORUS`/`BRIDGE`):

```bash
python3 ~/reaper-claude-kit/scripts/reaper_song.py ПАПКА [--name имя] [--bpm 108]
/Applications/REAPER.app/Contents/MacOS/REAPER -nonewinst ПАПКА/open.lua
```

`open.lua` открывает проект в новой вкладке, вешает RS5K на «Bass» и сохраняет.
Что внутри:

1. Папка проекта — та, что назвал пользователь (обычно `~/Documents/reaper/<имя>/`), добавить в сессию.
2. Генератор пишется на Python: MIDI инлайном в rpp, по айтему на секцию и
   дорожку, регионы секций (`MARKER n pos "Verse" 1` + закрывающий `MARKER n end "" 1`).
   Заголовок дорожки: `make_project.track_head`, цепочка: `suno_project.fx`, цвет: `suno_project.col`.
   Пример всей сборки — `suno_project.rpp()`.
3. VST без шаблона вешается lua: `TrackFX_AddByName(tr, "<строка из ini>", false, -1)`, затем `Main_SaveProject`.
   Проверено: работает через `-nonewinst`, проект сохраняется.
4. Открыть: `/Applications/REAPER.app/Contents/MacOS/REAPER -nonewinst script.lua`,
   внутри `Main_openProject("noprompt:<путь>")`.
5. Пересборка — **всегда под новым именем** `<имя>_ГГГГММДД_ЧЧММСС.rpp`, в новой
   вкладке. Если путь тот же, REAPER берёт проект из кэша, а lua сохраняет старый поверх нового.

## Живость (отзыв пользователя, 2026-10-09)

| На слух | Как сделано в `reaper_song.py` |
|---|---|
| дробь снейра линейной рампой ровными 1/16 — «механизм бьёт» | `snare_roll`: крещендо по кривой x^1.7, ведущая рука ±7, акцент на долю +8, разброс ±8, тихие (<88) — Snare Shallow Hit 43, форшлаги, подгон к концу −15 мс |
| сбивка по томам с нарастанием — «хорошо, разная сила удара» | `tom_run`: разные барабаны + шаг велосити; так и оставить |
| хэты 8-ми с акцентом на долю — хорошо | не трогать |
| велосити ровная по песне | `humanize`: дрейф раз в 2 такта (ударные ±6, бас ±7, гитары ±10), общий сдвиг на аккорд ±6, по ноте ±2 |
| аккорд гитары одной точкой | разнос струн 6 тиков вниз |

Одинаковые сбивки в каждом припеве тоже звучат машинно — у каждого своя.

## Проверка

Не «я уверен, что звучит», а замер. Рендер мастера и стемов — lua в открытом проекте:
`RENDER_SETTINGS 1` (мастер + стемы выделенных), `RENDER_FORMAT "evaw"`,
`RENDER_PATTERN $track`, выделить все дорожки, `Main_OnCommand(42230)`; ≈ 45 с на 2 мин.
Путь рендера — в скретчпад. **Lua меняет настройки рендера проекта**: предупредить
пользователя, если он потом рендерит сам.

| Замер | Норма |
|---|---|
| RMS каждого стема | не −240 (молчащий VST) |
| длина рендера | равна проекту; 119.27 вместо 120 с и скачущие ±90 мс атаки — сбой рендера, перерендерить |
| высоты баса (pyin по нотам) | первая сборка: 325/349 верно, промахи — ноты вне 28..39 |
| хрома гитары на долю аккорда | 24/24 такта припевов |
| сэмплы мастера > 0.999 | при дорожках 0/−2/−4/−4 дБ: 5553; при −6/−6/−6/−6: 18 |

Дальше — пользователю на ручное прослушивание: он слушает и рендерит сам.
