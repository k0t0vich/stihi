Чей выбор ближе к итоговому топ-32?

Представим, что каждый судья самостоятельно отбирает 32 работы по своим оценкам. Сравним этот выбор с результатом пяти способов подсчёта. Это реконструкция по оценкам, а не опрос судей: ничьи оставляют выбор неопределённым.

Совпадение с выбором судей

Для каждого способа показано среднее по шести судьям и наименьшее совпадение с одним судьёй. Значения — ожидаемая доля общих участников с учётом ничьих на границе.

Борда и Z-score дают один и тот же состав топ-32. Их среднее выше исходных оценок всего на 0,217 процентного пункта. Единого лидера для каждого судьи нет: например, у MoreGlory ближе Белл · топ-32. Как совпадает с каждым судьёй

Число в ячейке — ожидаемая доля общих участников из 32. Выберите судью, чтобы подробнее изучить его сравнение.

Кто совпадает, а кто различается

Вероятности прохода показаны для выбранного метода и судьи. Полное совпадение — оба значения 100%; разные значения или доли между 0 и 100% показывают расхождение или неопределённость.

Как устроен расчёт и что он означает

Личный топ-32 восстановлен по оценкам каждого из шести судей; неполный лист AzazeLLo_SS исключён. Это не опрос судей и не проверка объективного качества работ. Мы предполагаем, что при равных оценках судья не различает работы внутри ничейной группы.

Если ничья пересекает границу 32-го места, недостающие места распределяются равновероятно среди участников группы. Например, если из четырёх равных проходят двое, вероятность каждого — 50%. Тот же принцип применён к итогам метода. Выборы метода и судьи в ничейных группах считаются независимыми.

Для каждого участника перемножаются вероятности прохода по методу и у судьи; сумма даёт ожидаемое число общих участников. Делим её на 32 и получаем процент. Результаты округлены для показа, вычисления используют полную точность.

Ориентир максимального среднего построен специально под этот показатель: выбираются 32 участника с наибольшей суммой вероятностей прохода у шести судей. Это математическая верхняя граница для среднего по данной модели, а не независимый шестой метод.
