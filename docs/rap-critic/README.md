# Рэп-критик

Страница собирает промпт для разбора текста. ChatGPT и Claude открываются с промптом в ссылке и резервной копией в буфере; ChatGPT может сразу начать ответ. DeepSeek и Gemini открываются после копирования: промпт нужно вставить вручную. Если длинная ссылка не сработала, откройте пустой чат и вставьте копию.

| Действие | Команда |
|---|---|
| Обновить промпт на странице после правки `prompts/rap_critic_prompt.txt` | `python3 docs/rap-critic/build.py` |
| Проверить, что страница соответствует исходному промпту | `python3 docs/rap-critic/build.py --check` |
| Открыть локально | `python3 -m http.server --directory docs` и перейти на `http://localhost:8000/rap-critic/` |
