# Рэп-критик

Страница собирает промпт для разбора текста и копирует его в буфер обмена. Разбор выполняется в выбранном пользователем чате с нейросетью.

| Действие | Команда |
|---|---|
| Обновить промпт на странице после правки `prompts/rap_critic_prompt.txt` | `python3 docs/rap-critic/build.py` |
| Проверить, что страница соответствует исходному промпту | `python3 docs/rap-critic/build.py --check` |
| Открыть локально | `python3 -m http.server --directory docs` и перейти на `http://localhost:8000/rap-critic/` |
