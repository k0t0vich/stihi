Настройка API Ключа

Для работы приложения требуется ключ Google Gemini API.

Ключ сохраняется только в вашем браузере (LocalStorage).

Где взять ключ?

  1. Перейдите в Google AI Studio
  2. Нажмите "Create API key"
  3. Скопируйте ключ и вставьте сюда
