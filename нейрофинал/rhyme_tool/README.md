# Инструменты стихосложения

Два скрипта на общем словаре ударений `all_accents.tsv`
(1.68 млн словоформ, github.com/Koziev/NLP_Datasets, CC0):
- **rhyme.py** — подбор рифм (ниже).
- **scan.py** — анализ ритма и визуальный разбор строф.

## Анализ ритма (scan.py)
```bash
# текстовый разбор: карта слогов 0/1/2, размеры строк, регулярность, % слабоударных
python3 scan.py текст.txt
echo "строка стиха" | python3 scan.py -

# ВИЗУАЛЬНЫЙ разбор строф в HTML (как Fet.Online): цветные клетки слогов,
# разбивка по строфам (по пустым строкам), номера слогов сверху, статистика
python3 scan.py текст.txt --html            # -> текст_разбор.html
python3 scan.py текст.txt --html out.html    # своё имя
```
Коды слогов: **0** безударный (синий), **1** слабоударный (серый), **2** ударный (чёрный).
Строфы бьются по пустым строкам. Слова не из словаря помечаются `?`.

В HTML **текст и фон объединены**: каждая клетка = ОДИН СЛОГ с текстом внутри,
фон покрашен по ударности. Клетки фикс-ширины (регулятор ширины сверху страницы —
для длинных слогов). Слогораздел — по гласным (слог = согласные + гласная).
HTML-шаблон: `strofa_template.html` (плейсхолдеры `__DATA__` / `__TITLE__`).

# Подборщик рифм (rhyme.py)

Детерминированный поиск ассонансных/дактилических рифм по нашей памятке —
вместо перебора в голове. Работает на словаре ударений (1.68 млн словоформ,
`all_accents.tsv`, источник: github.com/Koziev/NLP_Datasets, лицензия CC0).

## Как устроено
- Из датасета берётся слово + позиция ударения (в файле ударение помечено `^`).
- Строится «рифмо-подпись» от ударной гласной с учётом:
  - **пар гласных** (а/я, о/ё, у/ю, э/е, ы/и) — ассонанс;
  - **пар согласных** (б-п, в-ф, г-к, д-т, ж-ш, з-с, м-н, л-р, к-х, с-ц-ч-щ-з);
  - **типа клаузулы** (male/fem/dactyl/hyper — по числу безударных после ударной).
- Отсекаются однокоренные (снятие приставок + сравнение корней).

## Использование
```bash
cd нейрофинал/rhyme_tool

# рифмы к слову
python3 rhyme.py проталины
python3 rhyme.py проталины --klauzula dactyl --limit 20 --min-score 80

# проверить конкретную пару (для аудита текста)
python3 rhyme.py --pair носа заноза
python3 rhyme.py --pair вполоборота ворота   # покажет однокоренные=True

# разрешить однокоренные в выдаче
python3 rhyme.py слово --allow-cognate
```

## Флаги
- `--klauzula male|fem|dactyl|hyper` — фильтр по типу окончания.
- `--limit N` — сколько выдать (по умолч. 30).
- `--min-score N` — порог созвучия 0..100 (по умолч. 55).
- `--allow-cognate` — не отсекать однокоренные.
- `--pair A B` — режим проверки пары: score, совпадение ядра, однокоренные.

## Оценка (score)
- +30 ударная гласная (класс) совпала
- +20 согласный сразу после ударной
- +10 согласный перед ударной
- +до 40 за длину совпадения хвоста
100 = сильная точная/ассонансная рифма; 55-80 = рабочая неточная.

## Workflow при написании текста
1. Задать опорное слово-панч (конец строки).
2. `python3 rhyme.py <панч> --klauzula <нужная>` → список кандидатов.
3. Выбрать слово ДРУГОЙ части речи, вписать в смысл.
4. Проверить финальную пару через `--pair`.
Так рифмы подбираются по словарю, а не наугад.
