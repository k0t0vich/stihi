РИФМА ПО ЯДРУ — правила (по разбору Есенина «Не жалею, не зову, не плачу»)
Дополняет рифмы.txt. Реализовано в rhyme-web (api/analyze.py: phon, rhyme_score, pair_info).

ГЛАВНОЕ: рифму держит ЯДРО = ударная гласная + согласная сразу после неё.
Хвост после ядра может расходиться — это не ошибка, а богатая неточная рифма.

1. СРАВНИВАТЬ ЗВУКИ, НЕ БУКВЫ
   | Пишется            | Звучит  | Пример                    |
   |--------------------|---------|---------------------------|
   | тс, тьс, дс, тц, дц | ц       | биться = [бица], ситца = [сица] |
   | ться / тся         | ца      | забыться = [забыца]       |
   | вств               | ств     | чувств = [чуств]          |
   | стн, здн, стл      | сн, зн, сл | честно = [чесна]       |
   | сч, зч, жч         | щ       | счастье = [щастье]        |
   | ь, ъ               | нет звука (перед я/ю/е/ё — й) | ранью = [ранйу] |
   | -ого / -его        | -ово / -ево | другого = [другова]   |
   | двойные согласные  | одна    | тленны = [тлены]          |
   | конечная звонкая   | глухая  | медь = [мет] ~ умереть    |
   | заударные о / е, я | а / и   | свежесть = [свежисть], реже = [режи] |

2. КЛАУЗУЛЫ: ЖЕНСКАЯ ≈ СЛАБЫЙ ДАКТИЛЬ
   Лишний заударный слог в дактиле (охваченный = охвАч-е-ный) проглатывается.
   плАчу / охвАченный — рифма, а не сбой размера.

3. БОГАТАЯ НЕТОЧНАЯ = совпало ядро, хвост разошёлся
   плАЧу / охвАЧенный, рЕЖе / свЕЖесть, Уст / чУвст(в), тлЕНны / благословЕННо.
   С ОПОРНОЙ (совпала и согласная перед ударной) — ещё богаче:
   желАНьях / рАНью (опорные л/р — пара сонорных), мнЕ / конЕ (опорная н).

4. ТОЧНАЯ ПО ЗВУКУ — не всегда банальная
   сИТЦа / бИТЬСя = [сица]/[бица]: на письме разные, на слух одинаковые, части речи разные.
   Банальной точную делает грамматика, а не совпадение звуков.

5. ТРИ УРОВНЯ ЗАМЕЧАНИЙ — ранжирование
   Ошибка — только то, что ломает рифму или размер. Предупреждение — повод присмотреться.
   Стилистика — рифма держится на грамматике: сменить часть речи у одного слова
   (на сайте — кнопка «Подобрать в нейросети»: готовый запрос с контекстом строфы).

   | Ранг | Уровень        | Что                                                    |
   |------|----------------|--------------------------------------------------------|
   | 1    | ошибка         | без рифмы                                              |
   | 2    | ошибка         | слабая рифма: ядро не совпало (балл < 70)              |
   | 3    | ошибка         | длина: слоги (силлаботоника) / ударения (тоника) выбиваются |
   | 10   | предупреждение | однокоренные                                           |
   | 11   | предупреждение | точная (ситца/биться, медь/умереть)                    |
   | 12   | предупреждение | точная с опорной (дым/молодым, холодком/босиком)       |
   | 13   | предупреждение | ударение? — рифмуется только при другом ударении (гОлоса, лОжите) |
   | 20   | предупреждение | провал: 5+ безударных подряд                           |
   | 21   | предупреждение | стык ударений (только в силлаботонике)                 |
   | 22   | предупреждение | слово не из словаря                                    |
   | 30   | стилистика     | глагольная (любить/забыть, сказал/упал)                |
   | 31   | стилистика     | одного состава: одна часть речи и форма (комом/домом, столом/окном) |

   Не замечание, а достоинство: богатая неточная (совпало ядро), ж ≈ слабый дактиль, усечённая.
   Тоже держат рифму: неточная с перестановкой — те же шумные после ударной, сонорные переставлены
   (стАРШим / стрАШНый); по сонорным (бОль / любОвь); по хвосту (гОрода / прОводы).
   Точная рифма — не замечание: норма для стиха.
   Глагольные и одного состава выделяются только по галочке «выделять односоставные рифмы»
   (стилистика, фиолетовым); без неё — нейтральная пометка в сетке.
   Глагольная и «одного состава» определяются морфологией (pymorphy3), не по буквам окончания:
   - глагольная — оба слова глаголы/инфинитивы (любить / забыть), а «жить / нить» — нет;
   - одного состава — одна часть речи и одна форма (комом / домом — оба сущ. в твор. п.),
     а «играя / мая» (деепричастие / сущ.) — нет; с опорной у падежных форм — богатая, не банальная.

6. ЛОМАНЫЕ СТРОКИ (лесенка, Маяковский «Облако в штанах»)
   Склейка: обрывок, у которого нет своей рифменной пары, приклеивается к следующей строке
   той же строфы — пока конец не найдёт пару (не длиннее 22 слогов).
     Нежные! / Вы любовь на скрипки ложите.   → одна строка, рифма лОжите / мОжете
     Это было, / было в Одессе.               → Одессе / Десять
     Восемь. / Девять. / Десять.              → одна строка
     иду — красивый, / двадцатидвухлетний.    → нет в ней / двадцатидвухлетний
   Пары ищутся и через пустую строку (малярия / Мария, лиги / книги).
   Приёмы Маяковского, которые считаются рифмой:
   - усечённая: одна открыта, у другой лишняя согласная — мозгУ / лоскУт, тонА / штанАх;
   - составная: два слова как одно — нЕт в ней / двадцатидвухлЕтний;
   - по другому ударению (омографы, просторечие) — лОжите / мОжете: предупреждение «ударение?».
   Размер определяется по интервалам между ударениями:
   | Интервалы         | Размер                          | Длину строки меряем |
   |-------------------|---------------------------------|---------------------|
   | 1 (и 3 — пропуск) | хорей / ямб                     | слогами             |
   | 2                 | дактиль / амфибрахий / анапест  | слогами             |
   | 1–2               | дольник                         | ударениями          |
   | 1–3               | тактовик (Маяковский)           | ударениями          |
   | шире              | акцентный стих                  | ударениями          |

Вывод: у Есенина почти нет точных «по буквам» рифм, но везде совпадает ядро.
Ритм держится тем, что ударная гласная и согласная после неё стоят на одном месте
ритмического рисунка строки — хвост после ядра звучит слабо и может быть любым.

Эталоны автора под это правило: оружие / ужинать (УЖ), синее / вынести (ИН, ы=и).
